## 设计决策

### 为什么不用 force-graph 3D?
- esm.sh 加载慢且不稳定
- 3D 视角对依赖关系图不是必要 (2D 更清晰)
- 3D 可留作 V2 增强项 (现在用 cytoscape 2D 跑通)

### 为什么数据用 OCR 而不是直接抓 HTML?
- 人教社 HTML 版是 Flash 翻书器 (book.swf), 不是结构化 HTML
- 教育部 PDF 是唯一可靠数据源
- OCR 准确率 90%+ (中文 tesseract 180 DPI), 适合结构化提取
