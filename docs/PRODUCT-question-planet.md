# 问游：问题驱动的探索产品

2026-10-23 · 本地产品评审版 · 尚未发布

## 产品定义

面向青少年的知识探索产品，首版先把五六年级孩子的独立使用做顺。用真实知识球呈现知识世界，用具体问题进入可操作实验，让孩子提出猜想、留下观察、解释自己的发现，再去追问。课程标准用于知识组织和内容核对，不直接等同于学习路线。

主要使用者是孩子。家长有独立的探索摘要入口，可以看到具体问题、真实观察、解释原话和检验记录；家长不需要坐在旁边才能完成流程。首版暂不做家庭账号、权限系统和独立家长应用。

价值假设：孩子愿意从一个自己的问题出发，通过操作和解释理解概念，并产生下一个问题。不能用点击、完成次数或一次答对证明理解；需另行开展儿童试用和教研审核。

## 产品结构与实际范围

| 页面 | 路径 | 实际能力 |
| --- | --- | --- |
| 官网 | /planet/#/ | 真实可旋转知识球、产品介绍、三个可进入的问题 |
| 知识世界 | #/explore | 1,906 个概念、14 个学科、筛选、旋转、缩放、点选 |
| 概念上下文 | #/explore/概念ID | 搜索定位、已编写的联系及原因、同领域参考入口、问题保存 |
| 探索问题 | #/question/shadow、halves、scale | 猜想 → 操作与记录 → 解释 → 新情境检验 → 保存发现 |
| 我的发现 | #/discoveries | 恢复草稿、回看观察和解释、保存及标记自己的问题 |
| 给家长 | #/family | 从当前浏览器的实际记录生成探索摘要，可下载 Markdown |
| 关于 | #/about | 内容范围、模型条件、来源及本地记录说明 |

三个完成的探索：光线角度与影长、整体变化与分数、长宽同时缩放与面积。图谱不是 1,906 节已编写课程。原始边尚有语义问题；儿童侧仅把精编关系解释为知识联系，其余概念显示同领域参考，不把未审核边当作先修推荐。没有加载旧题库进行能力评分。

## 设计与交互合同

当前艺术方向与取舍见 [ART-DIRECTION-wenyo.md](ART-DIRECTION-wenyo.md)。本轮已按用户选择采用明亮、有世界感的方向，并测试“问游”这一名称。旧名称与深蓝/陶土色方案保留在历史提交中。

- 视觉：日光中的浅色知识球，学科知识岛、实际概念节点、轻量关系；浅白 #fafbfe、正文 #202a3b、钴蓝 #3154ef。球体直接使用原图谱和几何，不嵌入旧页。
- 字体：系统无衬线，中文优先 PingFang SC / Noto Sans CJK SC；品牌桌面 94–150px、手机 60–69px；页面标题桌面 42px、手机 31px；正文 14–15px，使用行距建立层次。
- 首页：品牌、一个主要进入动作、直接连接三个问题的世界；第二屏先让人动手操作一个真实实验，随后展示更多问题、个人发现与家长摘要。没有假学生评价和规模数据。
- 布局：内容最大宽 1,320px；学习页由大实验对象与单一当前任务构成，760px 以下上下排列。手机世界按画布宽高比调整投影，保留整体形状。
- 核心交互：知识球拖动、缩放、键盘旋转与概念定位；直接拖动太阳改变光源角度，同时更新影子、数值与滑杆。滑杆和键盘提供等价操作。首页试玩不产生学习记录，正式实验仍需主动记录。
- AI：实验旁“想一想”入口展示其能看到当前实验；预置问题只是帮助填写，点击发送才请求 AI，不冒充已经发生的操作。
- 状态与记录：至少两组不同条件的主动观察才能进入解释；保留孩子原话与多次检验；错误可重试，完成不等于掌握。搜索、空态、未知路径、加载、失败和重试均有实际入口。
- 动效：进入时的短过渡、球体聚焦与对象即时变化；减少动态时关闭自动运动，后台/离屏停止绘制。没有给日常表单铺装饰渐变。
- 关系：只解释精编路径的实际原因；全量未核对边不包装成先修或 AI 洞察。

借鉴的是 Synthesis 的教具与角色分工、Brilliant 的交互画布、Heptabase/TheBrain 的上下文保持。问游表达自己的“问题 → 操作 → 解释 → 追问”过程，未照搬其页面或宣称其用户效果。参考来源与未完成的远端视觉核验列在艺术方向文档。InfraNodus 的缺口发现与 NotebookLM 的来源问答仍是能力参照，未把尚未实现的跨资料自动推理作为本版卖点。

## 数据、实验与 AI

图谱读取既有 web/data/graph_lite.json；不修改原始数据。三问题内容位于 content.mjs，纯计算、记录模型、报告和 AI 上下文位于 core.mjs。记录采用独立版本命名空间；不覆盖旧工作台数据，不宣称跨设备同步。清除浏览器数据会丢失记录，应先下载摘要。

实验是明确条件下的简化模型：平行光线/竖直木杆/水平地面；纸带必须平均分；面积实验同时缩放长和宽。SVG 与数值来自同一模型。内容引用 NASA 与 OpenStax；公开资料支持计算与原理，不等于教师已审核课程。

AI 由本机服务转接已有火山方舟服务，凭证只读 ARK_API_KEY 环境变量。默认模型 doubao-seed-2-0-mini-260428，可用 ARK_MODEL 覆盖。只发送当前问题、当前实验参数、最近三条观察和本次提问；不发送猜想、解释原文、家庭报告或完整历史。来源与可操作参数进入服务端提示；回复仅作为文本呈现。固定实验提示与实时回答分别标明。

真实接口抽测发现过数值表述偏差，已增加可操作范围和单位格子/原图份数的精确事实。数次通过不保证模型永远正确，正式开放儿童使用前仍需更广教研与异常评测。

## 运行与验证

需要 Node.js 22 和 Python 3。不需要新增前端构建依赖。

```sh
node tools/serve_planet.mjs --port 4450
```

打开 http://127.0.0.1:4450/planet/ 。缺少凭证时核心实验、图谱、记录和报告仍可使用，实时 AI 显示不可用。只使用静态 HTTP 服务也能运行核心产品；/api/status 不可用不会假装存在 AI。

```sh
node --test tests/learning-workspace.test.mjs tests/product-flow.test.mjs tests/globe-contract.test.mjs tests/planet.test.mjs tests/planet-server.test.mjs
python3 tools/validate_learning_quality.py
python3 tools/build_learning_relations.py --check
python3 tools/build_workspace_preview.py --output 新目录
```

服务只绑定 127.0.0.1，限制 Host/同源/请求大小/并发/频率；凭证不在输出包。公开部署需要独立处理认证、用量、儿童数据、跨设备存储、监测与内容审核，不能直接把本机预览服务暴露到公网。

## 下一阶段的验收

1. 由教研人员逐条审核三问题模型、解释、检验和引用，形成可追踪审核结果。
2. 让 5–8 名目标年龄儿童独立完成一次探索，观察是否不依赖家长、能复述观察与解释，以及是否主动追问；这是试用计划，不是已完成样本。
3. 用真实试用结果决定扩展内容还是修正入口；记录任务完成、解释证据与追问，不用虚构留存、能力或学习成效。
4. 用户审美接受后再完善账户与家庭权限、跨设备记录和内容生产审核流程。发布单独确认。
