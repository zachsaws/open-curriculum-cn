# 从问题到测量：本轮实施合同

用户已认可产品定义：有引导的探究学习，数学科学首发，孩子自主操作，保留知识球；真实使用验证后移。本轮先交付本地版本，不发布。

视觉主张：明亮、精确的户外测量台；一幅可操作场景承担主视觉，深色排版、细线和钴蓝动作色延续现有系统。

内容安排：首页问题入口与地球 → 用影子测旗杆的工作台 → 同光线与不同光线对照 → 自己的解释与条件迁移 → 发现、知识联系、家长摘要。

交互主张：拖动光线改变两条影子；受支持的 AI 建议由孩子主动执行；不同条件的观察可并排比较和恢复。动效只响应对象变化、观察加入和路径切换；减少动态与键盘提供等价能力。

同时修复：同词异义误路由、半杯自然问法的类比说明、AI 混合文本/JSON 泄漏、题外回复的来源误导。搜索实时输入保持本地处理，未经主动发送不交给 AI。范围识别仍有明确边界，不宣称无限语义理解。

内容依据：[OpenStax 8.7，Example 8.80](https://openstax.org/books/elementary-algebra/pages/8-7-solve-proportion-and-similar-figure-applications)，同一时刻用已知高度和影长求另一物体高度。使用平坦地面、竖直杆、平行光线的简化模型。界面显示模型条件、近似值与失效对照；不要求孩子学习三角函数。专业内容审核仍待完成。

验收：原有记录与三个实验可恢复；新单元完整到解释、条件迁移和报告；同条件影长比与高度比一致，不同光线时禁止把推算当作真实高度；AI 参数只来自注册动作、数值来自同一模型；问题误路由样例回归；手机、电脑、键盘、无 AI 与失败状态检查。
