# 增长 / 裂变作战手册（C 端 · 免费 · 品牌轨道）

> 目标：把「单概念知识卡」变成家长愿意转发的社交货币，让免费图谱从「能看」变「被转发」。
> 原则：不投流、不卖课、不碰学科培训红线。用真实痛点换自发传播。

---

## 一、钩子公式（所有渠道共用）

**痛点场景 + 一句反转 + 一张卡**

- 痛点：辅导作业崩溃、孩子说"不会"但说不上哪里不会、报班花钱却补不到点上。
- 反转：卡住往往不是这步难，是**之前某步没学透**——我们能指出"之前漏了哪一步"。
- 落点：生成一张知识卡，发到群里，不说话也有人看懂。

⚠️ 话术红线：只说「溯源 / 规划 / 查漏」，绝不说「提分 / 补课 / 逆袭」。双减下"培训"话术会触发分发限制。

---

## 二、冷启动渠道（按性价比排序）

### 1. 家长微信群 / 班级群（最高杠杆，0 成本）
- 打法：自己先测一个概念 → 生成知识卡 PNG → 直接发群里，**不写推销语**，只带一句"刚发现娃卡在 X，之前漏了 Y，给你们也看看"。
- 为什么有效：家长群是信任场，一张"一眼懂孩子差哪步"的图比任何广告都能引发"我娃是不是也这样"的焦虑共鸣 → 自发求链接。
- 节奏：每周 2-3 个群，挑不同学科概念（数学函数 / 语文阅读理解 / 英语语法），覆盖不同家长。

### 2. 小红书（长尾搜索流量）
- 笔记模板：「辅导作业的崩溃瞬间」+ 知识卡图 + 正文"不是娃笨，是新课标这步没接上"。
- 标题示例见第四节。带话题 #新课标 #家长辅导 #学习规划。
- 卡片图右下角留站点二维码，引流回站。

### 3. 视频号 / 抖音（30 秒演示）
- 脚本：拿一张知识卡，镜头从左"之前要学"滑到右"之后能学"，配音"你看，学会这个之前得先会这 3 步"。
- 不露脸、不说话也行，卡本身就是内容。

### 4. 公众号 / 知乎（信任沉淀）
- 长文：「2022 新课标下，家长怎么判断孩子卡在哪一步」→ 文内嵌诊断入口。
- 定位"帮家长看懂课标"，不是"教知识"。

---

## 三、裂变闭环（使用即传播）

每一张知识卡都带：**站点二维码 + 回流深链 `?from=share&concept_id=XXX`**。

```
A 家长测概念 → 出卡 → 发群
        ↓ 扫码
B 家长落地诊断页(预填 concept_id) → 自测 → 出自己的卡 → 再发群
        ↓
C …… 循环
```

- 不靠金钱激励，靠**社交货币**："我也能生成一张专属卡发群里"比"转发得积分"更耐转发。
- 回流用 `from=share` 参数区分，配合 M3 埋点即可算"每张卡带来几个新访客"。

---

## 四、可直接抄的文案（自然口吻，非 AI 腔）

1. 「昨晚辅导作业又崩了。后来才搞明白，娃不是这题不会，是前面有一步没吃透。这张图一眼就懂差在哪一环。」
2. 「新课标改完，课本顺序和咱们当年不一样了。给孩子测了一下，卡点清清楚楚列出来，比瞎报班踏实。」
3. 「不卖课不推班，就一个图谱：学这个之前得先会啥。免费，自己测，卡住的概念一键出卡。」
4. 「发给我家娃的'差在哪一步'卡片。有同款困扰的家长可以自己测，入口在图里。」
5. 「说实话不敢保证有用，但至少让你知道'不会'背后到底是哪一步没接上。比干着急强。」

---

## 五、衡量（对应 M3 埋点）

| 指标 | 含义 | 看什么 |
|---|---|---|
| 卡片生成数 | 用户愿不愿意"出卡" | 钩子是否够强 |
| 分享数 | 出卡后有多少人真转发 | 卡片是否够"可发" |
| 回流 UV（`from=share`） | 每张卡带来几个新访客 | 裂变系数是否 >1 |
| 诊断完成率 | 落地页是否接得住 | 英雄流是否顺 |

> 回流系数持续 >1，才说明裂变动了。否则先调卡片文案/二维码可见度，不急着加渠道。
