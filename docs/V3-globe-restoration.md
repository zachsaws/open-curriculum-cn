# 恢复知识球首屏 · 2026-10-23

用户指出：原先进入产品的知识球与震撼全貌模块丢失了。自主学习定位不授权移除这一核心入口。

视觉主张：恢复原版深色、真实概念节点构成的可旋转知识球，保留原来的空间感、学科分组与节点选择；不用地理地球贴图或新的装饰星空替代。

内容安排：首屏看知识全貌 → 按学科/搜索/节点探索 → 已编排的概念进入对应学习小节，其他概念继续参考探索 → 下方明确当前可学主题。学习页继续保持浅色、阅读优先的界面。

交互安排：原版拖动、缩放、点选与返回全貌保持；球体在离开屏幕时暂停绘制；减少动态效果设置下默认不自动旋转；用键盘与概念搜索补充鼠标操作。

实现边界：复用 `explore.html`、`3d.js` 与真实发布图谱，用明确的 product 嵌入模式做适配。原版无参数入口行为不变；不改原始课程数据、六节内容、题目和学习记录。仅允许已知概念映射到现有学习小节，不把全部概念包装成已完成课程。

## 本轮实现

- 首页改回原版真实 WebGL 球体，深色首屏铺满可视区域。数据、节点空间分布、学科分组、拖动/缩放/点选沿用原实现。
- 统一的产品导航保留；去掉嵌入页面重复导航。首屏进入当前可学单元，下面继续呈现主题；单元里的分数图解继续作为教学内容。
- 五个明确的原图概念映射到现有学习小节。已验证“分数意义”进入“平均分，才有分数”。其他概念可看直接联系与原版资料，并明确尚未编排完整课程，不伪造教学覆盖。
- 新产品模式的概念卡收起原始 OCR、审核台账等长字段；既有原版资料仍可单独打开。没有改写原始图谱数据或六节内容。
- 搜索支持按钮和键盘选择；球体支持方向键、加减号与复位键；暂停图标和实际旋转状态保持一致。减少动态效果设置下默认不自动旋转，离屏时跳过绘制。
- 跨窗口跳转只接受本源、本 iframe 的白名单消息，并只映射到明确的现有课程或主题目录。

## 验证边界

已跑通桌面实际球体、暂停和拖动、搜索→概念→对应学习小节、未编排概念→主题目录；手机 390×844、390×667、中屏 900×720 无横向溢出。短屏首屏包含完整球体区域。减少动态效果模式实测默认暂停。

19 项回归测试通过；原发布数据契约与派生一致性、模块语法、静态构建通过。学习内容专业复核和真实学习效果验证仍未完成，本轮没有提升相关审核状态。WebGL 与设备性能的长期兼容性未做全面覆盖；不将本机视觉检查作为用户审美接受。

旧版本预览保留，无推送、无部署。原版 `explore.html` 无 product 参数时保持其既有界面，新增样式和适配行为只在产品内嵌模式启用。

补充实测：方向键操作会暂停自动旋转，0 键复位后可重新开启；故意阻断 3D 脚本，超时提示与“重新打开球体”出现，解除阻断后重试恢复。临时网络阻断、缓存和动态效果模拟均已撤销，交付页面恢复自动旋转。原版独立入口的旧导航仍在，未出现新课程按钮。
