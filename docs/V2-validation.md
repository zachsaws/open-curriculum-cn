## 本轮完成

- 新增 `web/learn.html`：概念查找、学科/年级过滤、按概念展开的局部关系图、可访问的文本关系列表、关系依据检查、讲解/练习/来源检查面板。
- 沿用发布数据和按概念 payload；新增派生 `learning_relations.json` 保存原始理由/来源标记，使用图谱 SHA-256 防止错版本拼接。派生过程不提升任何审核状态。
- 默认隐藏跨学科关联；保留前置/进阶/关联类型与单独依据；重复邻居合并展示，关系记录不丢失；支持平移、拖动节点、缩放/复位及键盘节点导航。
- 四选一精确判分，未选不可提交，答题后看选项/参考答案/解析；暂停概念不进入练习；不将作答转换为掌握结论或前置缺口。

- 手机使用上下排列的局部图，非等比缩小桌面版；抽屉在关闭时不可被键盘误入，打开时隔离背景，支持 Escape/焦点循环；原生单选框、标签、tab 键盘切换、skip link、reduced-motion 样式。
- CI 增加发布数据契约、派生文件一致性与工作台规则测试。Pages 的实际部署工作流未更改，部署仍需用户授权及发布前进一步串联质量门槛。

## 还没有完成的验收

- 用户的视觉与交互接受尚未获得，当前是可体验的第一版实现。
- 教师没有复核本轮概念、题目和关系；没有真实家长/学生任务观察、迁移或 7 天保持数据。
- 内容语义污染、截断、模板关系和精确原始页定位尚未修复；本轮把这些状态揭示出来，没有伪造完整溯源。
- 本地存储无法跨设备同步，也没有账户/云备份；写入失败有降级提示，但本轮未在浏览器中真实注入配额不足。
- reduced-motion 已实现 CSS，未单独做系统设置切换实测；未做所有 14 学科逐题语义验收、大图压力测试或完整辅助技术审计。
- CI 修改仅本地验证，未推送触发 GitHub Actions；Pages 需另做发布依赖门槛。README 的旧宣传主张未在此次代码范围内批量改写。

下一步有限目标：先验收这条工作台路径；再由用户/教师确定一个学习目标，核对一小段概念—关系—题目链并观察真实使用。不要继续扩大题量或自动关联来代替验证。
