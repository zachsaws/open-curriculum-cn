# 统一探索单元 · 本轮设计与实施

2026-10-24。视觉主张：浅色纸面、深色排版和一件真正可操作的教具，探索对象与孩子的记录占据主位。保留知识球与既有品牌，改善学习工作台的层级和连续性。

内容安排：首页/搜索中的真实问题 → 与整体、分数、长度的关联 → 同屏纸带实验和 AI → 两次观察并置 → 自己解释与主动请求反馈 → 新情境 → 发现与家长摘要。

交互主张：拖动纸带端点直接改变整体；AI 基于同一模型建议受约束的下一次操作，孩子主动执行；记录保留不同条件的视觉快照，可恢复该条件。保留滑杆与键盘等价操作，并支持减少动态。

三个面共同约束：OpenStax 的分数与等值分数材料；实验模型的确切数值与参数；单元界面里的可执行动作。AI 不拥有另一个计算模型，不自动改动实验或将建议冒充已完成观察。

当前缺口：自由问法仍需可靠的范围识别；反馈原话需要明确主动提交；AI 超时、无服务、不可执行建议都需要真实状态；源资料待审核，不声称课程已教研审核或效果已证实。

本轮目标是把一个单元一起实现和验证，完整数学、科学课程与公开 AI 托管不在本轮冒充完成。
