# V2 学习工作台：设计与验收规范

## 设计立场

视觉：沿用当前深色、蓝色强调的知识地图气质，用稳定三栏、清楚文字和稀疏局部关系构成安静的学习桌面。主角是可读的知识内容和关系，不是球体旋转。

内容布局：左侧找到概念；中间看当前概念及直接邻居；右侧讲解、练习、来源。每个区域有单一职责。没有营销 hero、成就仪表盘和假统计。

交互：焦点切换有短促淡入；节点 hover/focus 有明确边框；检查面板内容过渡在 140–180ms 内；尊重 reduced-motion，不自动旋转，不做持续流动粒子。

参考页和机制见 `V2-product-review.md`：Heptabase 看导航/工作区/侧读、TheBrain 看焦点邻域/历史、InfraNodus 看由结构发起下一步检查。源代码不是视觉验收，浏览器自检也不代表用户审美验收。

## 搜索与导航

学科与年级按节点元数据过滤，不能根据 ID 猜年级；无结果可清除筛选。文本支持标题、ID；发布轻量数据不含拼音，本轮不承诺拼音检索。加载失败提供重试。概念列表可键盘选择。改变列表筛选不会偷偷改变当前概念。浏览器前进/后退恢复焦点；直链使用 `learn.html?concept=ID`，坏 ID 有明确状态。

初始空态给三个来自真实库的示例入口，但不声称已验证教学效果。用户能随时回到原 3D 全貌；原页面与生成数据不被覆盖。

## 节点与画布

当前概念视觉最强；前置记录置左，后续记录置右；关联采用独立开关并显示文字标签。默认只看一层，不做跨层因果推断。多条边连接相同邻居只显示一个邻居，但每条关系的独立依据仍可检查。过多邻居使用可滚动文本列表查看全部，不用截断假装只有几个。

点击邻居让它成为焦点，URL 与阅读面板同步；点击关系/“查看关系依据”只检查关系，不移动焦点。无前置记录写“暂无前置记录”，不写“你已经具备全部基础”。视图可以平移、缩放和复位；移动节点只是本次视觉位置，不改知识关系。缩放下限保证可恢复，所有画布操作都有按钮替代。提供关系文本列表，确保不依赖 SVG/WebGL 即可完成核心流程。

未经复核的前置/进阶边显示待复核状态；检查面板显示记录的方向、reason/source、审核状态。source 字符串和 reason 不是原始引用。不得给无审核记录的边打“已核实”标记。

## 阅读、来源与练习

讲解优先显示 teaching_voice/description；OCR 片段和学业要求放来源页，避免把污染文本排成确定事实。个人笔记有保存状态、存储受限提醒；复习标记可以撤销；本地数据与原错题本键名隔离，不清除旧历史。

来源页显示来源字符串、参考页码、原始片段和“页码/OCR 对应待核对”；链接到现有资源目录并如实说明不能直达原页。空字段明确说暂无。关系和内容复核状态分别显示。

练习复用现有概念 payload，只对符合四选一答案契约的选择题计分，暂停概念不进入练习。提交前必须有选择；提交后锁定本次答案，显示你的选项、标准答案、解析和下一题/再练入口。题目只有一题就显示“一题”，不能承诺五题。简答题提供对照参考而不自动判对错；本轮主路径先做选择题。结果描述具体作答，不据单题判断掌握、不诊断学习缺口。不得为演示生成新的“真题”。

## 系统状态与验证样例

必须覆盖：索引加载、概念详情加载、详情失败重试、离线/缺文件、空搜索、无前置、无邻居、无可计分题、暂停内容、无审核、直链不存在、写入失败、答对、答错、未答提交、快速切换概念时旧请求晚到、刷新恢复、前进后退、手机抽屉和 reduced-motion。

技术验收与内容验收分开：发布数据契约、派生文件一致性、关系分组/去重、答案判分、状态污染与直链检查通过；原始内容 hash 不变。该检查不证明教育语义准确，也不等于用户接受视觉方向。
