# 问游 · 产品与艺术方向重审

2026-10-23。用户已选择：明亮、有世界感和冲击力、交互像探索真实事物，避免学术工具感与幼儿化；先试“问游”。保留旧版本，不发布。

## 从反馈推断的偏好

偏好的核心是有原创概念和感知品质的消费产品：强视觉锚点、可信的材质与空间、短而自然的语言、操作后可见的变化。这里的判断来自用户对当前版本、早期知识球和跨项目设计的反馈，不宣称已掌握全部私人审美。

上一版的失败不是少了动效：深色低对比点云几乎没有可辨内容；球体像背景插图；首页标语和内容重复；实验在纸面表单里；AI 藏得很深；全站没有能够记住的品牌形象。自动检查不能修复这些问题。

## 三项设计决定

视觉主张：明亮、精确、带一点惊奇的可触摸知识世界；以日光下的浅色球体、清晰知识岛和钴蓝动作形成辨识度，避免宇宙壁纸与泛科技装饰。

内容计划：首屏由“问游”、短句“从一个为什么开始。”、可转动世界和三个真实问题组成；第二屏用可操作实验展示产品；随后呈现自己留下的发现和家长实际可看的内容；结尾只保留一个进入动作。

交互主张：球体拖动与概念定位保持空间连续；问题入口直接连接实验；试验后的数值、已记观察和下一步形成同一反馈；AI 从当前对象与最近操作出发。通过一个明确的页面进入过渡、球体聚焦和直接拖动太阳后的对象即时变化提供存在感，减少动态时关闭自动运动。

## 原创表达与借鉴边界

- Synthesis：参考可操作教具、孩子主体、家长了解结果的角色区分，不复制其学业焦虑与效果承诺。官方页面已读取；本轮远端浏览器截图超时，未据此宣称完整实测其学习产品。来源：https://www.synthesis.com/tutor
- Brilliant：参考共享交互画布与具体帮助，关注对象而非聊天气泡。当前官网已引入 Koji，先前只把它当题库的认识已过时。本轮官网来源：https://brilliant.org/ 。旧轮官方截图保留于 generated-md/knowledge-os-review-20261022/design-reset/references/。
- Cosmos：仅借鉴内容本身形成视觉层级、收藏与继续探索的思路，不复制图片墙；本轮读取官方页，远端视觉未完成验证。来源：https://www.cosmos.so/
- Heptabase / TheBrain：保留上下文、关系原因、返回位置；不搬入研究者工具的菜单密度。

问游的独有表达是“知识世界 → 一个问题 → 自己动手 → 留下解释 → 继续追问”。球体是导航，实验是认识事物的方式，AI 是看得懂当前情境的帮助。官网展示已存在的能力，不把未来生成任意课程作为现成卖点。

## 命名

推荐测试名：问游。问对应好奇与问题；游对应知识之间的自主探索。去掉“知识星球”这个功能名，保留球体作为核心交互。AI native 由操作、上下文和反馈体现，名字不堆 AI / 智 / 大模型。英文拼写 wenyo 作为本地设计标签，不声称已注册。

排除：问野已有同名 AI 自主空间（https://roam.xiaopingfeng.com/）；知屿已有同类知识社区（https://study.openeee.cn/）；知识星球已有成熟社群品牌（https://www.zsxq.com/）。问游公开搜索未发现明确同类直接结果，但这不是商标、域名或应用商店可用性结论。发布前独立核查。

## 本轮一起修正

1. 统一品牌、文案、色彩、字体层级与导航，重写样式而非继续叠覆盖。
2. 球体采用实际几何、照明和节点呈现；前景节点可选，背景内容不过分争抢；保留键盘和搜索等价入口。
3. 首页提供真实问题入口，减少解释产品的标语，官网下半部分用实际交互证明。
4. 实验扩大对象、精简任务，选项与观察反馈更清楚；让 AI 的当前问题帮助可发现。
5. 我的发现与家长摘要统一为轻量记录页，保留原文、实际观察、尝试与来源。
6. 保留相同存储合同和原图数据；不因为换名丢掉已有学习记录。技术契约、内容真实性、视觉接受分别验收。
