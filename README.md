# Open Curriculum CN

> 中国基础教育（K12）知识图谱开源基础设施
> 复刻 [Marble](https://withmarble.com/curriculum/) 的范式，但用中国数据，覆盖义教课标 2022 年版 16 门学科。

## 这是什么

把教育部《义务教育课程方案和课程标准（2022 年版）》+ 部编版/人教版教材目录 + 公开教辅结构，
抽取成结构化的**先决条件依赖图（prerequisite dependency graph）**。

每个节点 = 一个可独立教学/评测的**概念**（concept），不是教材章节。
每条边 = "学 A 之前必须先学 B" 的**先决关系**（prerequisite relation）。

## 跟 Marble 的区别

| 维度 | Marble | Open Curriculum CN |
|---|---|---|
| 学段 | 英美小学 1-6 | 中国义教 1-9 + 计划扩展高中 |
| 学科 | 数学、英语、科学等 | 16 门义教学科（语文/数学/英语/科学/道法/历史/地理/物理/化学/生物/信息科技/艺术/体育/劳动/综合实践） |
| 颗粒度 | 1,590 概念 | 目标 8000-12000 概念（更细，因为中国大纲更细） |
| 关系来源 | 课标 + 教研 | 课标 + 多教材版本（部编/人教/苏教/沪教/北师大）+ 公开教辅结构 + 教研论文 |
| 可视化 | 3D 漏斗 | 3D 漏斗（同 Marble 风格）+ 2D 列表 + JSON API |
| 协议 | Open source | CC-BY-SA 4.0 |
| 商业化 | 暂无 | 暂未商业化；保留 B 端 API/SaaS 路径 |

## 跟国内"知识图谱"产品的区别

松鼠 AI、科大讯飞、作业帮都有**闭源商业版**知识图谱。我们做**开源**版本。
目标不是抢他们的 C 端用户，而是给：
- 老师/教研员看全局、做备课
- 学术研究者用数据
- 中小教培机构做轻量级学情诊断
- AI 创业团队做教育产品时复用
