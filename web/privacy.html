1. 我们不收集什么

本网站是纯静态站点，部署在 GitHub Pages 上。我们（项目作者）没有任何服务器后端可以收集你的数据。

不收集

  • ❌ 姓名 / 邮箱 / 手机号（无需注册登录）
  • ❌ 答题记录（错题本 / 诊断历史）
  • ❌ 学习行为（点击 / 浏览 / 停留时长）
  • ❌ 设备指纹 / IP 地址 / User-Agent（除了 GitHub Pages 默认的访问日志）
  • ❌ 地理位置 / 学校 / 年级（除非你主动填）

GitHub Pages 默认日志

GitHub Pages 出于安全和反爬虫目的，会记录访问者的 IP 地址和请求路径，这些日志由 GitHub 持有，30 天后自动清除，我们无法查看详细访问记录（只能看到聚合 PV/UV 数据用于统计）。详见 GitHub Pages Data Collection。

2. 本地存储 (localStorage) 说明

为了提供"错题本"和"诊断历史"功能，本网站使用浏览器的 localStorage API 存储以下数据：

存储 Key内容大小目的
occ_history_v1诊断历史（最近 500 条）~1MB显示进度趋势图
occ_wrongbook_v1错题本（最多 1000 题）~2MB回顾错题 / 重做
occ_user_v1当前用户 ID（V1.1 班级模式）<1KB区分本地用户
🔒 关键事实 localStorage 数据只存在你当前浏览器的这个域名下：
  • 换浏览器 / 换设备 = 数据不见（除非用同一浏览器的同步功能）
  • 清浏览器缓存 / Cookie = 数据主动清空
  • 我们（包括项目作者）没有任何方式读取你浏览器里的 localStorage

如何清空本地数据

浏览器 DevTools → Application 标签 → Local Storage → 选 zachsaws.github.io → 点"Clear All"。或直接在浏览器设置里清缓存。

4. 第三方资源

B 站视频播放器

点击"📺 看讲解视频"按钮时，会加载 B 站官方 iframe 播放器。B 站可能在播放器加载时收集你的 IP / UA / Cookie。这是 B 站的隐私政策，不是我们的。详见 B 站隐私政策。

如果你是未成年人，且不希望留下 B 站访问记录，可以：

  • 不点"看视频"按钮（视频链接是公开的 B 站资源）
  • 退出 B 站登录态后再看

其他第三方

本站不使用：

  • ❌ 任何广告 SDK（百度 / 巨量 / 穿山甲）
  • ❌ 任何统计 SDK（Google Analytics / 百度统计 / 神策）
  • ❌ 任何社交分享 SDK（微博 / 微信）
  • ❌ 任何 A/B 测试 SDK

5. 未成年人保护

本项目主要面向 K12 学生（6-18 岁）。我们承诺：

  • 🟢 不收集任何未成年人个人信息
  • 🟢 不展示任何商业广告
  • 🟢 不引导填写个人信息（无注册 / 无登录）
  • 🟢 不接入可能追踪未成年人的第三方 SDK

建议家长 / 监护人：

  • 陪伴孩子首次使用时，浏览"使用说明"
  • 如不希望 B 站视频被观看，可点错题卡时跳过视频
  • 定期清浏览器缓存以清空本地错题本

6. 你的数据权利

由于我们不收集任何数据，你自动拥有以下权利：

  • ✅ 访问权 — 你的数据在 localStorage 里，DevTools 直接可看
  • ✅ 删除权 — 清浏览器缓存即删除全部本地数据
  • ✅ 导出权 — 错题本支持"导出 PDF"（在错题本主页 🖨 按钮）
  • ✅ 更正权 — 错题可手动从错题本移除
  • ✅ 拒绝权 — 不用即不受影响（无强制账号）
